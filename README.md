# Jodav Cleaning Services website

React, TypeScript and Vite. No backend. Bookings are prepared as WhatsApp messages.

## Run locally
    npm install
    npm run dev

## Build
    npm run build

## Deploy
Push to GitHub, import the repository in Vercel (framework: Vite), then add the domain jodavcleaningservice.com.ng.
